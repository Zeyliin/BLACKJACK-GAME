Blackjack is a very simple game that requires a certain amount of skill based on a certain amount of luck. The luck part has to do with the cards you are dealt and the skill has to do with learning some basic strategies, mainly knowing when to hit and stand. The goal of the game is to beat the dealer's hand by scoring 21 or as close to 21 as you can get without going over.
